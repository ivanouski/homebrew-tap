# homebrew-tap

```sh
brew install ivanouski/tap/<formula>
```

| Formula | Description |
|---|---|
| [box](https://github.com/mafflin/box) | Lists, prunes and stops docker containers, images and volumes, with a dashboard |
| [charta](https://github.com/mafflin/charta) | Tiny, lightweight CLI for quick notes, kept in a git repo |
| [istoria](https://github.com/ivanouski/istoria) | Bash history finder that forgives typos |
| [sndbx](https://github.com/ivanouski/sndbx) | Small wrapper around docker run for running coding agents in a sandbox |
